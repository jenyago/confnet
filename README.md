# ConfNet

**ConfNet** — MVP networking-платформы для участников конференций (B2B).

Мобильные клиенты (iOS / Android) + веб + личный кабинет B2B. Цель: networking и удержание аудитории между мероприятиями для участников, инструмент работы с аудиторией и маркетинговая база для организаторов.

## Продуктовая концепция

- Единый аккаунт, который переиспользуется между разными конференциями.
- Интерес-базед мэтчинг + базовые каналы связи.
- «Кто рядом» (гео / proximity).
- Лента, анонсы, регистрация на события, приглашения, промокоды.
- Retention-механики: повторные приглашения прошлых участников, программа лояльности, комьюнити / чаты / сторисы.
- B2B-кабинет: управление аудиторией, анонсы, push, retention-кампании.
- Бесплатно для участников за счёт маркетинговой базы.

## Что реализовано в этом MVP

Интерактивный веб-прототип (адаптивный под мобильные, max-width mobile layout):

| Функция | Статус |
|---------|--------|
| Единый логин / регистрация (роль участник / организатор) | ✅ |
| Профиль + интересы | ✅ |
| Мэтчинг по интересам + переход в чат | ✅ |
| Чаты и комьюнити (список + переписка с демо-ответом) | ✅ |
| Сторисы (горизонтальная лента + полноэкранный просмотрщик) | ✅ |
| «Кто рядом» (список + визуальная карта с точками) | ✅ |
| Программа лояльности (баллы, уровень Silver, награды) | ✅ |
| B2B-кабинет (анонсы, push, повторные приглашения) | ✅ |
| Лента / анонсы | ✅ |

Все данные демо, ничего не сохраняется. Работает полностью на клиенте.

## Запуск

1. Склонируйте репозиторий.
2. Откройте `index.html` в браузере (или запустите любой static server).

```bash
# Пример с Python
python -m http.server 8000
# затем http://localhost:8000
```

## Стек прототипа

- Чистый HTML + Tailwind CSS (CDN) + Lucide icons.
- Vanilla JavaScript, без сборки.
- Адаптивный mobile-first layout.

## Источник требований

## Открытые вопросы из ТЗ

- Бренд и целевой сегмент конференций.
- Модель монетизации (кто платит при бесплатном доступе для участников) и GDPR.
- Объём B2B-кабинета.
- Каналы коммуникации после мэтча.
- Proximity-стек (geo / BLE / NFC).
- White-label vs агрегатор.
- Приоритет: research first или сразу MVP.
